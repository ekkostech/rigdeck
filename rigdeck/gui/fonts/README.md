# Fonts

`AdwaitaSans-Black.ttf` is the weight-900 instance of GNOME's Adwaita Sans
(a fork of Inter), made with fontTools' instancer from the variable font in
the `adwaita-fonts` package. Blender's text objects cannot pick a weight from
a variable font, so the tank clip needs this static copy. Adwaita Sans is
licensed under the SIL Open Font License 1.1; see
`/usr/share/licenses/adwaita-fonts/` on an installed system or
https://gitlab.gnome.org/GNOME/adwaita-fonts.
